# Building-a-1.5-Crore-Multi-Sector-Equity-Portfolio
Designed a ₹1.5 Cr equity portfolio across 20 companies in 4 sectors: Banking, FMCG, Oil &amp; Gas, and Defense, using fundamental analysis of 10+ financial metrics. Built 4 Power BI and Excel dashboards to rank firms, assess risk, growth and valuation, and identify top-quartile stocks for allocation.
